# Schnitt 5.8.0

## Perfect Screen

A new production keyer for green and blue screens. Sample the background with the colour picker or let Auto Sample Edges read the corners, then shape the matte with Threshold, Softness, Black Clip and White Clip. Edge Feather cleans hair and motion, while Spill Suppression and Despill Amount remove reflected screen colour. The whole matte runs on the GPU and updates while you scrub.

## Animate Path Points

Shape, pen and freehand layers can now grow a rig of null controllers, one per point and optional Bézier handles. Open Edit Points and tap the new controller button, or use the layer menu. Show or hide the nulls, parent them to the layer, change controller scale, and bake the animation back into ordinary shape keyframes when the rig is ready.

## Flex Layout

Select several layers and open Flex from the selection bar. Flex measures their real bounds and packs them into wrapping rows with adjustable spacing, padding, wrap width, growth, vertical alignment and distribution. The result is written as normal transform values, so parenting, undo and export keep working.

## Motion Blur

Legacy motion blur effects now resolve to the working built-in effect, including the old motionblur1 to motionblur4 names. The preview no longer uses the fast two-pose smear for this effect, which could flash a dark frame on scaled or masked layers. Full motion blur still renders every sample on export.

## Theme and storage

The project settings sheet now uses the active theme scrim, the expression editor opens as a proper themed dialog, and the old Light label is now Daylight everywhere. Preview frames are capped at 256 MB and old preview tiles are cleaned on launch, so app data stays much smaller.

## Under the hood

Bounds are measured once per Flex run, path controllers read their transforms only when baked, and Perfect Screen keeps the matte in a single shader pass instead of allocating intermediate alpha buffers.
