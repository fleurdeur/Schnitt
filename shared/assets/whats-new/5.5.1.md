# Schnitt 5.5.1

## Tiles fixed
Tiles now maps each scene pixel back into the source layer with the correct transform. The effect also renders across the full scene instead of being clipped to the layer bounds, so a layer smaller than the canvas repeats across the screen.

## Imported Alight tiles
Imported Alight Motion Tiles effects use the same corrected mapping. The official shader math and Crop, Offset, Mirror, Offset Vertically and Angle controls are preserved.

## HDR and 10-bit previews
HDR, wide-gamut and 10-bit videos now get a small SDR preview copy before they reach the editor. The preview and the timeline thumbnails use that copy, so phones that hand the app a buffer in a layout it cannot sample no longer show green or blocked frames. The original file is still used for export, and normal 8-bit videos keep playing directly.

## Smaller fixes
The Tiles shader uses the layer size for its crop edge padding, matching Alight Motion. No other effect or extension behavior is changed.
