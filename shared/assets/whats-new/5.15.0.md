# Schnitt 5.15.0

This release fixes broken imported effects, restores the real Lens Blur and Zoom Blur, improves heavy-project playback, and makes the local MCP server usable with Claude custom connectors.

## Imported effects

- Every bundled external effect now compiles and renders instead of failing silently.
- SkSL loops, dynamic array reads and reserved names were rewritten without dropping keyframes, parameters or presets.
- Background, depth and mask effects still work in the Effects Library with editable properties.
- Added translations and choices for the restored blur controls.

## Real Lens Blur and Zoom Blur

- Restored the original parameters, sampling and falloff from the reference implementation.
- Lens Blur keeps its Spin and Zoom modes, sharp centre, feather and sweep.
- Zoom Blur keeps its distance-weighted and even sampling modes.
- Preview sampling scales with preview quality; paused preview, stills and exports use the full sample count.

## Heavy-project playback

- Heavy scenes now use a lower-resolution preview while playing even when automatic quality is off.
- The preview is rendered into a genuinely smaller surface and upscaled once, instead of allocating full-screen effect buffers.
- Nested groups now count toward the preview cost, so a busy composition cannot look cheap.
- Motion blur reduces its pose count only while playing; export keeps the full trail.
- Frame pacing drops display frames only when the measured draw time cannot keep up.
- Tested on a bundled 83-layer project: playback improved from single-digit frames per second to a smooth low-resolution preview, with full-quality export unchanged.

## Claude custom connectors

- The local MCP server now advertises OAuth protected-resource and authorization-server metadata, dynamic client registration, PKCE and refresh tokens.
- A 401 response points Claude at the discovery document, and the approval page accepts the existing bearer token.
- Claude connects from its cloud, so the panel now explains the required public HTTPS tunnel on port 443.
- A stalled client connection can no longer take the editor down.

## Agent fix

- Gemini function calls now preserve and echo thought signatures, fixing the missing-thought-signature error after tool calls.

## More

- Added regression coverage for nested preview cost and the updated MCP protocol.
- Exported video and still frames remain full quality.
