# What's new in 5.2.1

**The Schnitt Guide, TikTok and image results load more, and the yt-dlp tab now searches as well as accepts links.**

## New features
- **Schnitt Guide** - the home drawer button is called Help and opens the Schnitt Guide, with a new 5.2 feature list and colours that follow the app theme.
- **TikTok Load more** - another page of results loads at the bottom of the list.
- **TikTok XML from links** - the importer now follows XML links in a post, including Google Drive and Dropbox links, downloads the file, opens a zip if needed and imports the scene.
- **Pinterest and Cosmos Load more** - both image shelves load another page at the bottom.
- **Better image fallback** - Pinterest and Cosmos try the full image, its thumbnail and the other available sizes before giving up, so a broken original no longer stops the picture being added.
- **yt-dlp links and searches** - the yt-dlp tab accepts a YouTube Music or other media link, or a plain search such as clarity, and lists the matching audio with its title.
- **Fixed project preview** - the preview now sits below the status bar and uses a centred fixed-width layout.
- **Working Tracery AEX port** - the Tracery plug-in now gets a real Android effect that keys the chosen colour and draws boxes, labels, markers, connections and arrows instead of a shell with dead sliders.
- **Deep Glow 2 port** - the AEX glow shaders are rebuilt as a working Android effect with radius, exposure, threshold, threshold smoothness, tint, blend, aberration and source opacity.
- **AutoSway port** - AutoSway and its .ffx presets open as a live sway effect with type, axle, distance, speed, decay, lag, rotation and scale controls.
- **Flex shape port** - Flex JSXBIN packages get a working shape-warp effect with width, height, corner, bend, taper, skew, wave, rotation and offsets.
- **CRT Emulator port** - the included CEP plug-in now gets a native CRT effect with its twelve original styles, curvature, scanlines, RGB mask, aberration, glow, noise, flicker, grid and tint.
- **Puppet Auto Sway** - a one-tap Auto Sway button enables procedural sway on the puppet without keyframes, alongside the existing keyframe control.
- **Minimized plug-in windows** - minimising the Plugins window now leaves a small Plugins button and lets the editor work normally behind it.
- **Native plug-in property controls** - every plug-in exposes its generated effect properties inside the Plugins screen, with sliders, switches, choices and colour fields; Apply uses the values you set.
- **Schnitt branding everywhere** - AbsentMotion and Absent Motion names were replaced with Schnitt across the app and the full help guide.
- **Community presets** - a community page in the repository accepts presets and XML through a review queue. Approved files appear in one Presets section with Presets and XML subcategories.
- **New About page** - full app context, developer profile and links to wall (@fleurdeur), with a layout that follows the app theme.

## Fixed
- **Flex JSXBIN** - the locked-binary message is gone; Flex opens native shape controls and applies a real shape-warp effect.
- **Plug-in window minimisation** - the dismissed window no longer blocks the editor or the rest of the screen.
- **.ffx and .fxx packages** - preset-only folders are recognised and use the matching native effect instead of a blank generated placeholder.
- **AEX Tracery** - its properties now change the rendered effect; the embedded shader and parameter set were read from the plug-in and rebuilt in SKSL.
- **Project preview overlap** - the top of the preview no longer runs into the phone status bar.
- **Pinterest previews** - images that failed only at the original size now use the next working size.
- **Image adding** - a picture is only refused when every available size fails, not when the first one fails.

## Improved
- **Guide colours** - the guide uses the same light or dark palette as the app instead of the system default.
- **TikTok search** - more result pages and sources are merged, with Load more keeping the existing list.
- **Audio library** - yt-dlp results use the real item link for the download, so the selected track is the one saved.
- **Image library** - paging keeps the loaded grid and stops cleanly when a shelf has no more results.
