# Schnitt 5.5.2

## Imported Alight effects use working implementations
- Tiles, Luma Key and Wave Warp now switch to the built-in effects instead of an untranslated Alight shader.
- Imported keyframes and property values are kept and converted to the matching controls.
- Curated mappings now win over a bundled Alight shader, so imported links and XML no longer render as placeholders or noise.
- Luma Key has Low, High, Feather, Weighted and Invert controls.
- Wave Warp has the complete Alight controls: Phase, Direction, Spacing, Magnitude, Warp Angle, Damping, Damping Spacing, Origin and Screen Space.

## Editor and media
- Existing preview-copy, HDR, export fallback and device compatibility behaviour is unchanged.
