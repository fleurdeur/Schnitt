# What's new in 5.1.7

**Real Alight Motion shader definitions**, a working effect-XML compiler, and import-preserving effect IDs.

## Added
- Alight Motion effect-definition XML import. The importer reads real <params> and <shader> GLSL, translates the shader to Schnitt SKSL, and registers the effect with its actual parameter names and values.
- 108 portable Alight Motion effect definitions bundled from the real effect catalog. Effects already present in Schnitt are skipped by name/key instead of duplicated.
- Real shader compilation is lazy: Alight shaders compile when their effect is used or when an imported scene references them, keeping startup fast.
- Scene import now preserves a real Alight effect ID when a genuine ported definition exists, instead of replacing it with a generic built-in effect.
- Effects that need layer matrices, multi-pass buffers, or pass indices are rejected rather than replaced by an unrelated shader.

## Fixed
- Preset effect lookup uses full effect IDs and renders real effects.
- Plugin names use the document display name instead of storage UUIDs.
- Plugin effects resolve short/full IDs and attach to the selected or chosen layer.
- Unsafe arbitrary evalScript execution removed; common effect calls map to layer effects.
- System-light resolves to the green Daylight theme.
- Audio library labels are centered.
- Preset/TikTok category rows scroll horizontally.
- Media tiles are wider and use two-line labels.
- TikTok search/player/XML handling is cached, throttled and backoff-protected.
- Pinterest/Cosmos image searches are rate-limited and cached.

## Limitation
Adobe .aex files and encrypted Alight .ta packages remain native/encrypted binaries. Effect XML definitions with readable GLSL are ported; native machine code is not executed or replaced with a fake effect.
