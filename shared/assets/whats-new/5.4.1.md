# Schnitt 5.4.1

## Tiles now tiles correctly
- Tiles repeats the layer image across the screen with seamless wrapping instead of clamping and stretching the edge pixels.
- Mirror, alternating-row offset, vertical offset and rotation now match the Alight tile effect.
- Crop changes tile size without changing the layer aspect ratio.
- External Tiles keeps its Alight controls: Crop, Offset, Mirror, Offset Vertically and Angle.

## Circular Ripple is circular again
- Circular Ripple now creates rings around the layer centre, measured in screen space so the waves stay circular on any project size.
- Radius and Feather fade the rings out smoothly at the edge.
- Center X and Center Y now match the Alight Center control.

## Copy Background copies what is underneath
- Copy Background now takes the pixels already behind the layer and masks them to the layer shape, like an adjustment layer.
- Fill 0 keeps the background, Fill 1 keeps the original layer, and values between blend the two.
- Both the built-in effect and the Alight External Copy Background effect use the same behaviour.

## Under the hood
- Rebuilt the native engine with lift handling for Alight Copy Background.
- Added regression coverage for Tiles parameter mapping and Circular Ripple uniforms.
- Updated the effect library and translation release list.
