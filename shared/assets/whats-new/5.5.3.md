# Schnitt 5.5.3

## Export works on more phones
- Encoders are no longer rejected because their advertised size list disagrees with the project size. The encoder is now asked to configure the stream, with progressively simpler formats and automatic size fallbacks.
- Software encoders are used when a hardware encoder refuses the stream.
- Export verification no longer turns a successful file into "Export Failed" when the device decoder is busy or cannot decode its own output.
- Large exports get a longer verification decode budget.

## Imported Alight effects
- Alight shaders now use the layer texture size for pixel maths. Blur, edge, outline, noise and similar effects keep the correct radius when a layer is smaller than the project.
- Tiles maps directly through the layer matrix, so repeats stay aligned on rotated, scaled and nested layers.
- Inner Shadow is available as a built-in effect and imported Alight Inner Shadow keeps its blur, X, Y, colour and opacity keyframes.
- Luma Key has a Range mode for the newer Alight threshold formula, with the older formula still selectable.
- Imported property names, values and keyframes are preserved.
