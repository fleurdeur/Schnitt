# Schnitt 5.7.1

This is a compatibility, controls and performance release.

## Raster Extrude

- Raster Extrude is Alight Motion's Raster Extrude effect. Imported XML and links now keep all of its settings instead of reporting them as lost.
- Added the missing Shading Type, Ambient, Specularity, Light Color, Light Direction, Elevation, Interior Blend, Fade Color and Fade Blend controls.
- Added Width, Height and Edge Strength controls so imported extrusions keep their shape and march quality.
- Light, shine, shading, depth, interior color, position, scale and rotation continue to work and keep their keyframes.
- Existing saved Raster Extrude effects keep their old look.

## 3D layer controls

- The 3D layer panel now has touch sliders for position, rotation, scale and camera field of view, not only number boxes.
- Sliders group their changes into one undo step, so dragging is smooth and does not flood the history.

## Directional Blur

- Rebuilt on a 65-sample directional gather adapted from Keyflow's directional blur.
- The smear is measured from the visible layer size, so it behaves the same on small and large layers.
- Alight directional blur keeps its strength and angle when imported from XML or a link.
- Old saved directional blurs stay compatible.

## Effect imports and duplicates

- Bundled Alight copies of effects that already have a native implementation are no longer listed twice.
- Imported Alight Motion Blur now resolves to Schnitt's own keyframe-aware Motion Blur.
- Curated Rays, Cube, Grid and Page Curl rules keep their settings and keyframes instead of falling back to a flat placeholder.

## Depth maps

- Depth maps now match the model's native 518 px working size instead of producing a larger matte than the model can fill.
- Long clips use a lower depth sampling rate while keeping the original timestamps, duration and alignment.
- Depth inference runs with backend-aware parallelism, so NNAPI and XNNPACK devices no longer fight over too many jobs.

## Performance

- Adaptive preview reacts to real render times, not only the selected quality.
- Heavy scenes automatically lower the background preview and pre-render resolution in steps, while light scenes keep full detail.
- Scene size, fps, total time, layer maps and media maps are cached, so large projects no longer re-parse the same scene data every frame.
- Layer effect lists are reused until the layer changes.
- Timeline row lookup uses an id map, and imported custom effect files are cached until they change.

## Fixes

- Media URI decoding handles encoded dot segments and Windows file paths safely.
- Interrupted update downloads no longer leave an open part file on Windows.
- Added migration tests for every Raster Extrude control and for animated Ambient and Fade values.
- The full unit suite passes.
