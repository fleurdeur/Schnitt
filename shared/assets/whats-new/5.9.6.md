# Schnitt 5.9.6

Motion Blur now renders the real layer, plus import and support fixes.

## Motion Blur

- The layer is no longer replaced by an offscreen sample stack that could turn images and videos into flat white or black.
- Every shutter pose is drawn directly from the layer itself, so the image, video frame, colours and alpha are preserved.
- The current frame is always drawn sharp and fully visible on top of the trail.
- The trail follows position, scale and rotation keyframes, Auto-Shake and Oscillate.
- Still layers draw once. Moving layers draw the shutter poses behind the current frame.
- Trail poses use plain source-over, so Screen and Add layers no longer stack into white and Multiply layers no longer stack into black.

## Import warnings

- Importing now shows a warning popup when effects or effect settings could not be carried over.
- The popup lists effects this build cannot run, effects that had to be converted, and settings that could not be mapped.
- The same warnings are written to the debug log.

## Debug log

- Added Settings > Advanced: debug log.
- The log is plain text, with timestamps, version, device, project loads, import reports, conversion gaps, engine failures and crashes.
- Copy the whole log or clear it from the same screen.

## Still included

- Converted effects keep their mapped values, keyframes and easing.
- Unmapped animated rows and unknown effects stay in the project file.
- Mirror has Blend Mode and Offset.
- Project opening stays fast.
