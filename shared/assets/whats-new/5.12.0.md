# Schnitt 5.12.0

The AI agent is now part of the main editor, with a secure Gemini key and full project control.

## AI agent in the editor

- Open Tools and choose AI agent to chat with a creative assistant that can edit the open project.
- It can add layers, text, media, audio and effects, change properties, animate keyframes, write expressions and rewrite the project XML.
- It can inspect the project, pick effects from the full library and set their editable controls.
- Media can come from your device or from a direct link, and is copied into the project when you ask.
- It can work across the whole timeline, from a single title to a complete multi-layer edit.
- Every edit is undoable, and the agent can undo or redo its own work.
- The agent has a written guide to Schnitt's layer model, XML format, timing, keyframes and effects, so it does not have to guess.

## Replicate a reference video

- Attach a reference video in the agent panel and ask for a full replica.
- The video is studied for its full flow: shot timings, cuts, camera moves, text, assets, colour, transitions, effects, music and beat sync.
- The agent then rebuilds that structure in the open project instead of only describing it.
- Missing source assets can be replaced with close procedural stand-ins when needed.

## Private by design

- Your Gemini API key is encrypted with Android Keystore.
- The key is never stored in the project, debug log, release notes, local MCP server or device backups.
- It is only sent to Google's Gemini API, in a request header, over HTTPS.
- A reference video is uploaded to Gemini only when you attach it yourself.
- No key or conversation is uploaded anywhere else.

## Checked import and tools

- The local MCP server remains available and now exposes media, audio, effect and XML tools as well as layer and keyframe tools.
- The same tool set powers the built-in agent, so the two surfaces stay in sync.
- The MCP server is still off by default, local network only and protected by a bearer token.

## Smoother large projects

- Effect shaders compile only when a project or browser actually needs them.
- Opening a project no longer waits for the whole effect catalogue before the first frame appears.
- Used shaders are compiled after the project is visible, then the preview refreshes.
- Heavy projects keep the existing adaptive preview quality and frame skipping.

## Under the hood

- Added 25 project tools, including media import and replacement, effect discovery and editing, layer attributes, reordering and project settings.
- Reference video upload uses Gemini's resumable file upload and waits for processing before editing begins.
- The agent conversation stays in memory only and is never written to disk.
