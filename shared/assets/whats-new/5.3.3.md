# What's new in 5.3.3

**ISF and ISF4AE shaders now import with their real shader inputs, DynamicFX-style GLSL is picked up from plug-in packages, and unknown script/native packages get distinct procedural effect families instead of one generic tint.**

## New features
- **ISF importer** - reads the ISF JSON header and fragment shader, including bool, long, float, point2D, colour, angle and percent inputs.
- **ISF built-ins** - supports TIME, TIMEDELTA, FRAMEINDEX, RENDERSIZE, isf_FragCoord, isf_FragNormCoord, IMG_THIS_PIXEL, IMG_THIS_NORM_PIXEL, IMG_NORM_PIXEL and IMG_PIXEL.
- **ISF4AE package support** - ISF files inside unpacked ZXP, ZIP and 7z plug-ins are found automatically and become keyframeable Android effects.
- **GLSL plug-in shaders** - DynamicFX-style GLSL and standalone frag/glsl/shader files are detected and translated into SkSL.
- **Distinct semantic families** - unknown plug-in names are routed to separate grid, map, text, flow, camera, beat, glass, blur, glow, glitch, warp, sharpen and colour shaders.
- **GridTrend family** - grid line rendering with amount, radius and tint controls.
- **GEOlayers family** - map-style contour rings and grid overlay controls.
- **TextExploder family** - scanning text shimmer and displacement controls.
- **Flow family** - directional streak blur.
- **Camera3D family** - zoom and vignette camera treatment.
- **beatEdit family** - audio-style pulse brightness.
- **Glass family** - refraction, wobble and shine controls.

## Fixed
- ISF image inputs bind to the layer image instead of being ignored.
- ISF percent inputs are passed to the shader as normalized values.
- Plug-in shader parameter rows remain in the separate scrollable property section.

## Improved
- Plug-in discovery now checks ISF .fs/.isf files before generic shader scraping.
- Unknown AEX/ZXP/JSXBIN packages still produce different effects per semantic family, with editable controls, even when no shader text exists.
