# Schnitt 5.9.3

A smaller, faster build with more reliable Alight Motion import.

## Smaller download

- The standard APK is substantially smaller. Code shrinking and optimization are enabled again, native engine libraries are stripped, and the optional Aurea backend is no longer bundled in the standard download.
- The redundant 64-bit fallback engine is gone; 32-bit builds keep their fallback. Nothing in the editor structure was removed.
- Aurea preset support remains available as an opt-in build for ARM64.

## Effects that work

- Fade In and Fade Out now change layer opacity directly. This works for shapes, text, video, images, groups and imported Alight layers, and it combines with opacity keyframes instead of replacing them.
- Motion Blur no longer turns layers white. Blur samples are kept inside the layer surface and use a normal alpha fade.
- More Alight effects are handled by the native motion renderer instead of being guessed into an unrelated effect. Oscillate, Blink, Flicker, Pulse Opacity, Spin, Pulsate, Swing, Jitter, Shake and Scale Assist keep their original controls.
- Effects that cannot be matched safely are left out instead of being rewired into a different look. Explicit Alight rules still take priority, so stacked effects keep their order and fall back automatically.
- Turbulent stretch, text spacing and gradient map imports keep their settings.

## Faster opening

- A project file is read once when opened, and its version snapshot is written in the background.
- Effect matching uses direct lookup tables, and slow-motion normalization no longer rescans the whole layer list for every layer.
- Media lookup caches resolution details, and local files are checked before the content resolver.
