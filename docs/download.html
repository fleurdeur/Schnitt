Before you install

Three small things.

Android protects you from silent installs. Here is the whole ritual.

01

Allow this browser

When Android asks, allow installs from the app you downloaded with. This is a one-time permission for that browser, not a system-wide switch.

02

Open the APK

Pull down the notification, or open Downloads and tap the Schnitt APK. The package installer shows the version and the signer before it commits.

03

Update over the old one

Every release uses the same signing key. Installing a newer APK keeps your projects, presets and plug-ins in place. No uninstall step.

Signed, not repackaged.

Every APK on the release page is signed as CN=Schnitt. The site only links to the GitHub release assets owned by the repository; it never hosts a modified copy.

Pick by chip, not guesswork.

Universal contains every native library. arm64 is smaller and covers modern phones. armv7 is the 32-bit fallback. If you are not sure, universal is the honest answer.
