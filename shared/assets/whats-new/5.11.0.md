# Schnitt 5.11.0

Better imports, smoother playback, and a theme that matches the editor.

## Replace missing effects

- When an imported project uses an effect that is not available, the import warning now offers Replace effects.
- Every missing effect is listed with its old name and properties.
- Pick a replacement from the whole effect library, ranked by the closest name and controls.
- The layer, its timing, its properties and every keyframe stay in place.
- Effects that were imported but only partly matched are listed too, so nothing is silently dropped.
- The same repair button appears on the import preview screen.

## Frame rate

- Added 144, 165 and 240 fps to project settings.
- Choose Custom in the frame rate list to type any rate from 1 to 240 fps.

## Export result

- The export result screen now follows the app theme instead of forcing a dark panel.
- Buttons, text and icons use the same colours as the rest of the editor.
- The finished file name, location, size and preview remain visible.

## Smoother projects

- Preview resolution now drops further on heavy scenes with many effect layers, keeping the timeline responsive on low and mid range phones.
- Adaptation reacts sooner and steps back up when frames are fast again.
- Complex projects draw preview frames at a lower cadence while audio keeps its full timing, so playback no longer fights the effects.
- Light projects keep full frame rate and full preview quality.

## 291 more shader effects

- Added missing Alight-compatible shader effects from the reference library, without duplicating effects that were already present.
- Duplicate names and duplicate source effects were removed.
- Staged and native reference entries that could not run on our engine were left out instead of adding dead buttons.
- The extra effects are parsed once and their thumbnails are stored as normal static previews, so opening the browser stays fast.

## FFamp media engine, opt-in

- Added the FFamp native reader for arm64 devices.
- It is off by default and can be switched on or off in Settings > Playback.
- It reads additional containers and track headers, with a safe fallback to the platform reader.
- The FFamp library is included in the universal APK as well as the arm64 APK.

## Launcher category

- The launcher activity now declares the video app category as well as the application video category, so launchers such as Smart Launcher place Schnitt under video or media instead of tools.

## Effect fixes

- Edge Detect now exposes style, spacing, threshold and invert controls, including a two colour ink mode.
- Halftone gains strength and phase controls.
- Hue and Saturation gains Classic, Keep Brightness and Video styles.
- Checker uses the newer pattern shader.

## Still included

- Motion Blur draws the real image or video.
- Debug log records imports, conversions, project opens and failures.
- Every imported effect keeps its editable properties.
