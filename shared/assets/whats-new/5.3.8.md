Schnitt 5.3.8

Alight effect library
- The complete 315-effect Alight Motion definition set stays available in the External library.
- Property labels now resolve inline strings and @string references, so sliders, colours and switches show their real Alight names.
- Duplicate parameter ids in imported effect XML are collapsed instead of producing unusable controls.

Smarter imported-effect matching
- An Alight effect that is not shipped by name is matched by effect name, id words, property names and the visual family instead of being ignored.
- Matching properties keep their values, keyframes and easing; properties are also matched through labels and compatible types when ids changed.
- The import report now lists the replacement effect and every setting that could not be mapped, so nothing is silently discarded.
