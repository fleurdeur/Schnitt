Extensions · .sc

Make Schnitt
your own.

An extension is a small, portable .sc bundle. It can change colours, specific icons, effects, layout and safe timeline behavior. It is data, not code — Schnitt reads it, applies it, and never executes it.

Download Auto Scroll Read the manifest guide

Install once

Open Home → Tools → Extensions → Import .sc. Schnitt validates the bundle, copies only its supported files, and keeps your property values. Restart once to apply it.

Sandboxed reader

No JavaScript, DEX, native libraries, HTML or shell. The reader enforces a manifest, an allowlist, path checks, per-file limits and an 8 MB total cap.

One format, six categories

Behavior, Theme, Icons, Effects, Automation and Layout. Each category has a small, documented surface instead of an unrestricted app hook.

Quick start

Five minutes to a bundle.

A .sc file is a zip. Rename the zip after you add a manifest.

1 · Create the folder 
my-extension/
  manifest.json
  theme.css        (optional)
  icons/icons.json (optional)
  effects/*.json   (optional)
  layout/*.json    (optional)
  README.md        (recommended)
2 · Zip it 
# any zip tool works; the suffix must be .sc
zip -r my-extension.sc my-extension/*
3 · Test

Import the bundle in Schnitt, open its card, change the declared properties and restart. The extensions page never installs a bundle whose manifest is missing or whose paths leave the bundle.

4 · Share

Send the .sc file directly or publish it with a project/preset. Keep the README next to the bundle so people know which properties are safe to change.

The official extension suffix is .sc. APK, DEX, JAR, SO, JS, HTML and executable files are rejected.

Reference

manifest.json

Every bundle starts here. Unknown fields are ignored; unknown categories, capabilities and property types are rejected.

{
  "schema": 1,
  "id": "auto-scroll",
  "name": "Auto Scroll",
  "version": "1.0.0",
  "author": "your-name",
  "description": "Keeps the timeline on the playing layer.",
  "category": "behavior",
  "capabilities": ["timeline.follow"],
  "properties": [
    { "id": "enabled", "label": "Follow during playback", "type": "toggle", "default": true },
    { "id": "mode", "label": "Follow", "type": "choice",
      "options": ["Playing layer", "Selected layer"],
      "values": ["playing", "selected"], "default": "playing" },
    { "id": "snap", "label": "Snap layer to centre", "type": "toggle", "default": true },
    { "id": "speed", "label": "Scroll speed", "type": "slider",
      "default": 1.0, "min": 0.25, "max": 3.0, "step": 0.05 }
  ]
}

Categories

behaviorSafe timeline behavior. Requires timeline.follow.
themePalette colours from theme.css.
iconsHome/Tools vector icons from icons/icons.json.
effectsOne or more effect JSON files in effects/.
automationSafe playback automation. Requires automation.safe.
layoutSupported layout values from layout/*.json.

Capabilities

timeline.follow, theme.css, icons.home, effects.custom, layout.tools, automation.safe.

Capabilities are a closed list. A bundle cannot request file access, network, app internals, another extension's files, or arbitrary UI.

Custom controls

Properties are part of the extension.

Declare only what your extension understands. Schnitt renders the controls and stores the chosen values.

toggletrue / false. Example: enabled, snap, loopPlayback.
sliderNumber with default, min, max, step. Stored as text, read as a bounded float.
choiceoptions are labels, values are the strings your reader consumes. Both lists must be the same length.
textA single line, capped at 512 characters.
colorA single hex colour. Themes normally belong in theme.css.
Theme category

CSS that can only touch the palette.

Use familiar custom properties. Schnitt reads hex colours from --palette-name declarations and ignores selectors, URLs, imports and everything else.

/* theme.css */
:root {
  --home-bg: #0b0f0c;
  --card: #121a15;
  --navy: #e6f2e9;
  --home-ink: #cfe0d5;
  --accent: #7ed9a0;
  --accent-deep: #183326;
  --timeline-bg: #080b09;
  --preview-bg: #050706;
}

Supported names

Every name in the Schnitt palette: TopBar, PreviewBg, TimelineBg, Panel, Card, Navy, HomeBg, HomeInk, Accent, AccentLit, AccentDeep, OnAccent, Line, Gold, Warning and the rest.

Kebab-case is converted to the palette name, so --home-bg → HomeBg. Invalid colours and unsupported names are ignored.

Icons category

Replace a specific icon.

Icons are vector path data, not images or HTML. Supported names are the Home and Tools buttons.

// icons/icons.json
{
  "home.projects": {
    "path": "M5 3h14v18H5Z M9 8h6 M9 12h6 M9 16h4",
    "stroke": true,
    "width": 1.8
  },
  "home.tools": "M4 12h16 M12 4v16"
}

Names

home.projects, home.templates, home.tools, home.plugins, home.community, tools.extensions.

The path uses the same SVG path syntax as the app icons. A path can be up to 16 KB. Scripts and URL references are rejected.

Effects category

Ship an effect with its own controls.

Each file in effects/ is a Schnitt effect definition. It appears in the normal Effects library under Imported, with keyframeable properties and its own shader.

{
  "id": "my-lens",
  "name": "My Lens",
  "category": "distort",
  "description": "A small radial lens with a strength control.",
  "params": [
    { "id": "strength", "label": "Strength", "type": "float",
      "default": 0.5, "min": 0.0, "max": 1.0, "step": 0.01 }
  ],
  "sksl": "uniform shader image; uniform float2 amSize; uniform float strength; half4 main(float2 p) { float2 uv = p / amSize; float2 d = uv - 0.5; float r = dot(d,d); return image.eval(p + d * r * strength * 40.0); }"
}

Use an id prefixed with your extension id. Effects are compiled by the normal graphics engine; a malformed shader is rejected and never becomes a native code path. See the existing effect JSON files for presets, choices and multi-pass examples.

Layout category

A few honest layout switches.

Layout is deliberately narrow. The supported value is the Tools grid column count, so a layout extension cannot move controls into an unsafe or unusable position.

// layout/tools.json
{
  "surface": "tools",
  "toolsColumns": 2
}

Manifest property

Declare a toolsColumns slider with min 1, max 3 and step 1. The bundle remains a normal layout category extension and is toggled from the Extensions screen.

Automation category

Small, predictable playback rules.

The safe automation hook is loopPlayback. When enabled, playback restarts at the beginning at the scene end. It does not change speed, frames, audio or project data.

{
  "schema": 1,
  "id": "loop-playback",
  "name": "Loop Playback",
  "category": "automation",
  "capabilities": ["automation.safe"],
  "properties": [
    { "id": "loopPlayback", "label": "Loop at scene end", "type": "toggle", "default": true }
  ]
}
First extension

Auto Scroll, explained.

Bundled and enabled by default. It follows the playing layer vertically and only touches the timeline scroll.

Properties

Follow during playbackMaster switch.
FollowPlaying layer or selected layer.
Snap to centreCentre the row, or only scroll when it leaves the middle band.
Scroll speed0.25x–3x. Changes the ease duration only.
Smoothing time80–1200 ms base ease.

What it never does

It never changes the playhead, frame, playback clock, audio, project XML or export. It does not create keyframes and it stops following when playback stops. The timeline can still be scrolled by hand.

Security model

No shortcuts into the app.

The reader is intentionally boring. That is what makes it safe to share extensions with strangers.

01

Allowlist only

Manifest, README, LICENSE, theme.css, icons/icons.json, effects/*.json and layout/*.json. Everything else is rejected.

02

Path and size checks

Absolute paths, .., backslashes, duplicate entries, executables and oversized archives are rejected before install.

03

Data, never code

No JavaScript interpreter, DEX loader, native library, HTML panel or network request. CSS only sets colours; icons only set path data.

Extensions still run inside the same process as the app. A malicious shader can be expensive to render, so install bundles you trust and keep effects small. Schnitt reports a failed extension instead of hiding it.
