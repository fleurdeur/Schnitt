# Schnitt 5.5.0

## Extensions in Tools
Tools now has an Extensions button. Import an official .sc bundle, choose a category, change the properties the author declared, and restart once to apply it.

## Six extension categories
Behavior, Theme, Icons, Effects, Automation and Layout are visible in the app. Every bundle declares its category, its capabilities, and its own controls.

## Auto Scroll
The first bundled extension follows the layer under the playhead while the timeline plays. It only moves the vertical timeline scroll. Follow mode, snap to centre, speed and smoothing are editable in the extension card.

## Themes, icons, effects and layout
Theme extensions use a small CSS palette reader. Icon extensions replace specific Home and Tools vector icons. Effect extensions add normal keyframeable effects. Layout extensions can choose the Tools column count. Automation extensions can loop playback at the scene end.

## Safe reader
The .sc reader accepts a manifest and documented data files only. It rejects path traversal, executables, native libraries, scripts, HTML, duplicate entries and oversized archives. Extensions cannot read Schnitt internal files or bypass permissions.

## Performance and storage
Extension archives are parsed once per change and cached for preview, icons, effects and themes. The timeline follow behavior only reacts when the playing layer changes. Interrupted installs are cleaned up, stale temporary extension folders are swept, and the Extensions screen shows the storage used.

## Documentation
The website now has a full extension guide at fleurdeur.github.io/Schnitt/extensions.html, and the README lists every category and the Auto Scroll extension.
