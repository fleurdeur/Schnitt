# Schnitt 5.3.6

## Alight Motion links
- Share links are resolved across alight.link, alight.page.link, alight.to, alightcreative.com, alightmotion.com and their subdomains.
- Supports /am/share/u/.../p/... and query-style u/uid and p/pid/project links.
- Reads public project metadata, checks every package URL Alight exposes and accepts publicly readable Storage packages.
- Package downloads are streamed to disk with a 3 GB ceiling and ZIP validation.
- Alight ZIP packages no longer need Schnitt's own manifest. Any package containing scene XML and media is imported, with media matched by declaration, signature or filename.
- If Alight refuses to release the package, Schnitt now explains that clearly instead of showing Unsupported file type.

## General
- Removed the strict manifest requirement that rejected valid third-party project packages.
- Raw XML, ZIP, AEX and plug-in imports keep their existing paths.
