# What's new in 5.1.4

**Image library**, a compact **audio effect shelf**, a smarter **TikTok browser**, fixed **presets**, and a cleaner **AMOLED green** release.

## New features
- **Image library** in the media section. Search public **Pinterest** and **Cosmos** image results in a scrollable grid, preview an image, then hold it to place the original in the timeline with no re-encode.
- **Audio effect shelf** - the audio layer Effects button now opens a bottom section layout instead of the old full-screen browser.
- **Tone section** - Bass Boost, Warm, Air, Vocal Clarity, Telephone, Muffle, Radio and Cut Low.
- **Dynamics section** - Compressor, Punch, Limiter, Noise Gate, Soft Gate and Vocal Level.
- **Space section** - Small Room, Hall, Stadium, Plate, Echo, Ping Pong, Slapback and Underwater.
- **Pitch section** - Chipmunk, Deep Voice, High Pitch, Low Pitch, Robot and Whisper.
- **Applied tab** - bypass, delete and edit every audio effect property in the compact panel.
- **TikTok browser** in Tools. Search public Alight Motion effects, colour grades, transitions and presets with a custom list and in-app video preview.
- **Import XML** from a TikTok post's public description and page content.
- **Request caching and backoff** for Pinterest, Cosmos, TikTok and image requests so searches do not hammer the same site.

## Presets
- Presets now open with a real gradient layer instead of a plain white rectangle.
- Every preset thumbnail uses a compressed vector placeholder with the effect preview composited over it.
- Preset effects are applied only after the effect catalog is ready.
- Preset categories: Colour, Shake, Light, Retro and Motion.
- All included presets are free and use Schnitt's own effect shaders.

## Audio
- yt-dlp installation now lives only in the **Audio Library**, where it belongs.
- TikTok's import-audio action uses the installed add-on without duplicating its installer UI.
- Audio extraction remains up to 320 kbps.
- Audio effect JSON import remains available.

## Fixes
- Puppet is hidden on audio layers.
- FAB panels no longer overflow the visible area.
- Light themes use the green identity and the preview background follows the theme.
- Plugin panels keep their position, size and minimized state.
- Preset loading no longer produces empty white layers.

## Optimizations
- Coil image loading and disk caching for the image library.
- Serialized, throttled and cached search requests for Pinterest, Cosmos and TikTok.
- Cached effect catalogs/properties and reused plugin WebViews.
- Lighter pre-render encoding with more look-ahead and reduced flicker.
- Faster ONNX session reuse for Depth Anything V2.
