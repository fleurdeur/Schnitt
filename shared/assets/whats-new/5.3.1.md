# What's new in 5.3.1

**The native Skia engine has been rebuilt from source, Alight Motion multipass effects now use real per-pass Skia filter targets, and the previous engine is kept as a fallback.**

## New features
- **Rebuilt native engine** - libamengine.so is compiled against the pinned Skia source for arm64, armv7 and x86_64 instead of using the previous prebuilt binary.
- **Real native pass targets** - multipass Alight Motion effects now create one Skia runtime-shader filter per pass and feed each buffer target into the pass that reads it.
- **Per-pass buffers** - horizontal, vertical, distance-field and encoded-buffer effects keep their intermediate targets instead of flattening every pass into one shader.
- **Old engine fallback** - the previous engine is packaged as libamengine_legacy.so and is loaded automatically if the rebuilt engine cannot load on a device.
- **Old effect format support** - the inline multipass shader is still sent to the engine, so the legacy engine and old projects continue to render.

## Fixed
- **Multipass compatibility** - nested-effect passes and layer-space transforms still fall back instead of rendering an incorrect native chain.
- **Engine loading** - all engine entry points now use one loader, so the fallback is applied consistently across preview, export, audio effects and tracking.

## Improved
- **Pass accuracy** - buffer reads in the second and later passes now sample the actual output of the earlier pass.
- **Packaging** - the rebuilt engine is verified per ABI during the release build.
