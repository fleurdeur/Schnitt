# Schnitt 5.17.0

## Import a project from a link
Paste an Alight Motion share link or a direct project file. Schnitt reads the title and picture first, so you can check it before importing.

## Recommended effects
The effects browser now begins with three suggestions for the selected layer. It spots green screens, beat marks, short clips, cut-out pictures, and dark footage, then ranks the effects that fit.

## Arrange the Tools page
In Change layout, hold a tool and drag it anywhere on the grid. The arrow buttons still work for precise moves.

## Easier grouping
Select several layers and use the labelled Group button. Group and Mask and Group and Exclude are now inside the Group options.

## Better Alight Motion imports
More older projects keep their settings, including Oscillate, Move Along Path, 360 Reorient Sphere, lens and box blur, Glass, Glow Scan, Clouds, and Displacement Map.

## Bundle the effects a project uses
Project packages now carry imported AEX effects, so a project opens with the same look on another phone.

## Faster opening and closing
Projects open with the engine and media steps running together. Closing returns to the home screen immediately while the final save and thumbnail finish in the background. Small phones start with a lighter preview and raise it when paused.

## Face and eye guides
Eye Blink and Hair Flow can place themselves from a detected face. Nothing is guessed when no face is found.
