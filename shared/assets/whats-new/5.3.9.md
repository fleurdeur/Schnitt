# Schnitt 5.3.9

## Community, without the issue thread
- The official Schnitt site now has one community shelf for presets and XML projects.
- Upload is a drag-and-drop form with progress, a private status link, and human review. No GitHub account and no issue creation.
- The app reads approved community entries from the live shelf, with the old archive kept as a fallback.

## Updates outside the app
- The update check now posts a real system notification while Schnitt is closed or in the background.
- Checks run every 6 hours, resume after a reboot, and the notification has direct Download and Open actions.
- Notifications still respect the update-check setting, ignored versions, and Android notification permission.

## Site and release plumbing
- Download always resolves the latest GitHub release and starts the APK download directly.
- The site has a bottom navigation bar: Home, Download, Community.
- Release data on the site refreshes automatically when a new version is published.
