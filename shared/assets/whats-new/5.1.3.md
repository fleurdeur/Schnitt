# What's new in 5.1.3

**Puppet**, **Transform recording**, a faster **pre-render**, floating **plugins and AEX effects**, real **Depth Anything V2**, and a greener **AMOLED** look.

## New features
- **Puppet** - select a layer and open **Puppet** below its tools. The panel has three sections: **Pin**, **Mesh** and **Sway**. Turn on **Add Pins**, tap the preview to place pins, then drag a pin to bend the layer like a mesh. Pin mode, rotation, scale and per-pin sway are all editable. The panel uses the same bottom-tab layout as the **+** menu, and the preview can still be pinched to zoom and moved while you work.
- **Puppet Sway** - the **Sway** section keyframes the sway amount, speed and angle at the playhead, so movement is recorded as animation instead of a single fixed value.
- **Transform recording** - the **Move & Transform** panel now has a record button in its top-right corner. Press it to keyframe position, size, rotation and opacity at the current time, start playback, and let every change add a keyframe while you move the layer. Press it again to stop.
- **Puppet, Mesh and Sway descriptions** - the panel explains each section with short labels taken from the Flow puppet workflow: pins bend the picture, mesh controls triangle density and expansion, and sway waves a chain of pins like hair.
- **Hold Play menu** - holding Play now shows a compact pre-render and playback menu with **Loop** beside the quality choices. The duplicate pre-render control in the preview rail was removed.
- **Plugin floating windows** - plugin panels and script UIs open in a draggable, resizable window with a **minimize** button, an **Open** restore control, saved position and size, and a **reset** button.
- **Plugin properties** - a selected plugin shows detected controls from its own files, a **Layer** dropdown for choosing the target layer, and the normal effect settings so every mapped property is editable.
- **Plugins on layers** - every selected layer has a **Plugins** button that opens the imported plugin list.
- **AEX import** - the Effects Browser has **Import effect**. AEX files are read through their PE/PiPL metadata, then ported to a compatible global shader with editable properties. Native Windows machine code cannot run on Android, so the effect contract and properties are ported instead of executing the binary.
- **Depth Anything V2** - the **Depth map** button on video layers downloads the real Depth Anything V2 small ONNX model and processes every frame into a grayscale depth video. The model is downloaded on demand, not bundled in the app.
- **Custom audio library** - paste a site URL in the audio library. It reads playable audio from generic pages and adds fallbacks for Deezer, Bandcamp and SoundCloud, plus yt-dlp when the downloader add-on is installed.
- **Beat detection from Mark Beats** - select an audio layer and use **Mark Beats** to open the floating beat window. It detects BPM and beats with Bass, Vocal or Full bands, sensitivity, BPM range, and bakes clean transform keyframes exactly on the beats.
- **Quick actions for plugins** - imported plugins now show clearer names, versions, vendors and descriptions, with duplicate imports replaced instead of listed twice.
- **Clipboard image** - the Media section keeps pasted image bytes original, with no preview-sized re-encode.

## Look and feel
- **AMOLED green** - the main theme is true black with a soft, eye-comfort green accent.
- **Green Daylight** - the Daylight and light themes now use the same green identity instead of orange.
- **Readable text** - dim labels, captions, home text and secondary controls have stronger contrast in every theme.
- **Theme-aware preview** - the preview background follows the selected theme, so the light themes no longer show black letterbox bars.
- **Better press feedback** - buttons now show a rounded glow and border in their own shape instead of a plain rectangular opacity change.

## Faster and smoother
- **Faster pre-render** - lower preview-cache size and lighter JPEG encoding, more look-ahead frames, and nearest-frame drawing while the cache catches up.
- **Less flicker** - cached playback draws the closest ready frame instead of blanking while the next frame decodes.
- **Lighter plugin UI** - the effect catalog is loaded once, the WebView and its JavaScript bridge are reused, and plugin properties are cached.
- **Faster Depth Anything** - ONNX Runtime session reuse, optimized graph, and multithreaded CPU inference.
- **FAB layout** - the close button and quick actions no longer fall below the visible area. The section tabs sit below the content and all controls fit.

## Fixes
- **Depth map export error** - the int8 model could report `ORT_NOT_IMPLEMENTED`; the app now uses the full fp32 Depth Anything V2 model.
- **Pre-render duplication** - removed the second pre-render control from the preview rail.
- **Plugin windows** - position, size and minimize state no longer reset every time a plugin opens.
- **Export limits** - device capability checks no longer block an export before it is attempted.
- **Audio extraction** - extraction now supports up to 320 kbps and defaults to the highest quality.
- **Clipboard temp files** - pasted images are no longer deleted when the project keeps a reference to the original bytes.
- **App identity** - the app now advertises itself as a video app to launchers.
