# Schnitt 5.6.0

## 3D camera tracking and stabilization
- The 3D button in the layer tools now opens a dedicated 3D panel for shapes, text, drawings, models and cameras.
- Camera track solves a flat surface from four points and writes real 3D Location, Rotation and Tilt keyframes to the camera.
- Stabilize runs a two-point inverse track to lock the selected clip against shake.
- Toggle depth sorting and edit X/Y/Z, 3D rotation and scale with keyframe buttons.

## Expressions in keyframes
- Every transform property can use a small expression language: time, t, frame, value, sin, cos, wiggle, noise, clamp, smoothstep, random and more.
- Expressions are baked to ordinary keyframes, so preview, export and imported XML keep working exactly as before.
- The source expression is stored on the property so it can be edited again.

## Adaptive preview and effects
- Adaptive preview drops detail while playing and returns to the chosen quality when paused. Toggle it from the preview quality bar.
- New Headbop effect adds a beat-driven bounce, sway, tilt and squash accent with editable properties.
- Deep Glow and the existing Alight-compatible effects remain available in the Effects Library.

## Import and export fixes
- Keeps the 5.5.3 encoder fallbacks, software-encoder support and best-effort export verification.
- Keeps imported Alight property names, values and keyframes intact while using corrected layer-size uniforms.
