How it works

  1. Upload your preset or XML. GitHub opens its upload page; sign in if asked.
  2. The file is reviewed by wall (@fleurdeur). The status below changes from Pending to Approved.
  3. The app reads only approved entries, so the Presets screen stays clean.
  4. The app shows one Community section with Presets and XML subcategories.

Only upload files you made or have permission to share. No personal data. Do not upload paid or copied presets.
