# What's new in 5.2

**Plug-ins now get their own Android effects**, updates install from the latest GitHub release, and TikTok, the audio library and the projects home are simpler and more reliable.

## New features
- **Real plug-in effects** - an imported plug-in now gets its own effect with its own SKSL shader instead of being pointed at an existing built-in effect.
- **Automatic shader conversion** - shader text found inside a plug-in package is converted to Android SKSL, and its uniforms become editable effect properties.
- **Unknown plug-in conversion** - when a native binary has no readable shader, the app builds a deterministic Android effect from the plug-in's own name, parameters and files, so each plug-in keeps its own look.
- **One-tap update chooser** - the update card lists every APK in the latest release, with ARM64, ARMv7, Universal and x86_64 choices and their sizes, and starts the update from the selected file.
- **Latest release on GitHub** - update checks now read fleurdeur/Schnitt automatically, with a cached copy, ETag revalidation and a saved fallback so a rate limit or a short network error does not break the update screen.
- **Project preview before the timeline** - imported projects open a preview first: live playback, scrubbing, automatically matched media, tap-to-relink assets, imported-effect status and **Go to timeline**.
- **Import XML button** - the Projects tab has a direct Import XML action even when no project is selected.
- **Load more audio** - the audio library has a **Load more** button at the bottom for longer royalty-free and custom shelves.
- **TikTok without filters** - the category chips are gone; the screen is just the search field and button, and the query is sent exactly as typed.
- **TikTok preview** - results show their cover picture and open in a native video player, with a WebView fallback only when the direct video cannot play.
- **Load more TikTok results** - search collects results from several pages and sources instead of stopping at the first handful.
- **Beat bookmarks** - Marks Beat now bakes bookmarks into the timeline instead of adding keyframes.

## Fixed
- **Effect grid crash** - effects with the same ID no longer crash the grid with “Key was already used”.
- **Floating window overlap** - a floating card's content no longer draws over its drag header or resize grips.
- **WebView renderer crashes** - TikTok and Help survive a stopped WebView renderer instead of taking down the app.
- **TikTok audio fallback** - direct audio saving works on devices where the bundled downloader runtime is not available.
- **Help label** - the Help entry and its title now use the app name, **Schnitt**.
- **Update failures** - a failed release request keeps the last good release and shows a useful retry state instead of an empty card.

## Improved
- **Plug-in shaders** - converted shaders keep their own uniforms, colours, points and sliders, and a broken shader is reported instead of being replaced by an unrelated look.
- **TikTok search** - multiple result pages and sources are merged, duplicates are removed, and covers and titles are read once and cached.
- **Audio library** - paging keeps the loaded list, removes duplicates and only shows **Load more** when another page exists.
- **Update downloads** - the existing verified download, resume and signature checks are reused for whichever APK the user picks.
- **Startup and browsing** - release data and plug-in effect definitions are cached, so revisiting a screen does not repeat the same work.

## Compatibility
- Plug-ins that ship a readable GLSL or SKSL shader are converted directly. Native binaries that do not contain shader text are rebuilt from their own parameters and signature as a generated Android effect. Multi-pass host-only effects that need hardware-specific buffers still fall back to the generated effect instead of borrowing an unrelated built-in.
