# Schnitt 5.4.0

## Every Alight effect now has a real effect
- All 315 bundled Alight Motion effects open with their real names, thumbnails, descriptions and parameter controls.
- Bend, Glass, Pixelate, Clouds, Cube, Kaleidoscope, Tiles, Wave Warp, Tunnel, Streaks, Halftone, Color Tune and dozens more are now wired to Schnitt's own shader for the same job instead of showing a flat placeholder colour.
- Imported XML projects and Alight links keep their original effect IDs, keyframes and property names, so the saved animation still animates after import.

## No more stretched layers
- Fixed a shader naming collision where a Size parameter replaced the image size. That was the cause of the stretched, edge-pulled look on effects such as Pixelate, Block Noise, Mosaic, Hex Array and Long Shadow.
- Image size and time are now separate engine uniforms for imported and aliased effects.
- Tiles and tile-shift effects now render with correct aspect ratio and no stretched layer edges.

## Stronger fallbacks
- When a direct Alight shader cannot be compiled, Schnitt uses the matching built-in shader before ever showing a placeholder.
- Multi-pass shaders, blur targets, backdrop effects and automatic motion effects keep their own controls.
- Effect sliders, choices, colours, points and switches are usable, keyframeable and saved per layer.

## What's New fixes
- Release notes links and buttons now open the correct page in the app.
- Release notes keep readable text on every theme.

## Under the hood
- Cleaned up effect parameter parsing, labels, ranges and defaults.
- Added regression tests across the full bundled effect library.
