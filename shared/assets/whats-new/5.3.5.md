Schnitt 5.3.5

Export
- H.264 export no longer stops when the requested size is unsupported.
- The app now tries other advertised H.264 encoders, aligned sizes and progressively smaller even sizes while preserving the project aspect ratio.
- Software encoders remain available as a fallback, so low-end phones can still export.
- Automatic fallback dimensions are written consistently to the encoder, muxer and render surface.

Effects and AEX plug-ins
- Imported AEX files are converted into real effect definitions with editable properties instead of blank native entries.
- Tracery AEX detection now reads names and vendors from the full binary string table, so its marker controls are available.
- Native AEX imports from the plug-in installer and the effects library both register in the Imported/External catalog.
- All bundled Alight Motion effect definitions are shown in External, including effects whose names overlap built-in effects.
- Added texture, xyz, orient, hue-disc and float property parsing for imported effect definitions.
- Unknown effects in imported XML are matched to the closest installed effect by property names and semantic family.

Alight links
- Added handlers for alight.link, alight.page.link, alight.to, alightcreative.com, alightmotion.com and the Firebase share host.
- Share links are resolved to the user/project IDs, metadata is fetched from the public Alight cloud function, and the project package is downloaded before import.
- Downloads are size-limited and validated as ZIP packages.
- Existing XML import remains unchanged.

Fixes
- Reverse keeps short clips in memory and avoids temporary YUV disk round-trips.
- Plug-in imports keep the password and progress flow.
