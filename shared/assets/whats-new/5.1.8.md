# What's new in 5.1.8

**A real ExtendScript/JSX interpreter**, CEP effect execution, and AE matchName mapping.

## Added
- Rhino-based ExtendScript/JSX interpreter running on-device.
- Adobe DOM shim for `app.project.activeItem`, layers, selected layers, transforms, effect parade, masks, undo groups, alerts and common layer creation calls.
- AE effect matchName mapping into real Schnitt effects:
  - Displacement Map, Wave Warp, Easy Levels, Hue/Saturation, Box Blur, Glo, Unsharp Mask, Sharpen, Tile, Vibrance and more.
- Plain JSX script plugins now show a native script panel with a Run action instead of pretending to run through a browser.
- CEP `evalScript` calls are routed through the interpreter, so common panel scripts can add real effects to the selected layer.
- Script-applied effects use the normal layer effect stack, real properties and undo history.

## Improved
- Plugin names use document display names.
- Preset effects resolve real full effect IDs.
- Light/Daylight theme fixes, centered audio labels, scrollable category rows and readable media tiles.
- Alight Motion effect-definition importer from 5.1.7 remains active with lazy shader compilation.

## Limitation
- JSXBIN is encoded ExtendScript, not readable source. The interpreter handles readable JSX; locked JSXBIN cannot be executed without a decoder.
- Native AEX machine code still cannot execute on Android. The app reads metadata and maps supported AE effect contracts, but does not claim a 1:1 native AEX shader port.
