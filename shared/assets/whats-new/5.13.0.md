# Schnitt 5.13.0

This release focuses on speed: faster project opening, smoother playback, faster media loading, snappier depth maps and a responsive timeline.

## Smoother playback

- The bottom timeline no longer redraws every layer label and clip at the full display rate while the project plays.
- It follows the preview at a steady drawing rate, so scrubbing and playback stay responsive even in long projects.
- Preview quality now adapts sooner when a scene is heavy, and recovers when frames are fast again.
- Picture textures are coalesced instead of forcing a full render for every imported image.
- Project pictures are decoded in parallel when a project opens.

## Faster opening and media

- Decoded project pictures are cached on disk, keyed by the source file version, so reopening a project does not decode every photo again.
- The cache is lossless and automatically stays within a bounded size.
- The first preview frame no longer waits for every picture to finish loading.
- Media already cached appears immediately and is refreshed when the remaining pictures are ready.

## Depth maps and pre-render

- Depth map generation no longer probes the model on every run before doing real work.
- Depth inference reuses scratch buffers, reducing allocation and memory pressure.
- Two to four depth workers now share the work according to the device.
- Pre-render uses a faster lossless preview frame format and less idle delay.

## Local MCP over HTTPS

- The local MCP server now speaks HTTPS, which modern AI agents require.
- A private certificate and key are generated on the device and kept in app-private storage.
- The certificate is available from the MCP panel and the /certificate endpoint so a client can trust it once.
- The server is still off by default, local network only and protected by a bearer token.

## AI agent improvements

- Agent answers now stream, so long edits no longer look like a dead connection or time out while waiting for one large response.
- The status line shows what the agent is thinking and writing, plus a plain description of each project tool it uses.
- Tool rounds were increased and editor bridge waits were extended for large projects.
- Reference video processing no longer blocks a worker thread while Gemini prepares the file.

## Imported colors

- Color properties imported from Alight XML and links now keep component colors, packed integers and short hex values instead of falling back to the default.
- Color keyframes are converted too, so imported color animation stays intact.
- This applies to curated conversions, fallback matches and already-imported native effects.

## Auto Scroll

- Auto Scroll now follows the playing layer by default instead of sweeping through every row.
- It starts from the bottom and ignores the topmost layer by default, so a pinned overlay no longer keeps the timeline stuck.
- Existing Auto Scroll installs are upgraded automatically.

## More

- Added a Telegram community button in Settings that opens t.me/schnitts.
- Kept every existing project, effect, keyframe and import behavior intact.
