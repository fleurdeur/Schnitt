# Schnitt 5.3.7

## Update notification
- Schnitt now checks for a new release in the background through Android WorkManager.
- When a newer version exists, a system notification appears even when the app is closed.
- The notification shows the installed and available versions and opens Schnitt when tapped.
- The first background check runs shortly after launch, then every 12 hours.
- Notification permission is requested once on Android 13 and later.
- The check respects the existing Check for updates setting and ignored versions.

## Link import progress
- Alight link downloads now show a progress bar and the downloaded and total package size.
- Non-link imports show an importing state instead of an unexplained spinner.
- Progress stays visible while the package is prepared and imported.

## Playback performance
- Removed per-frame blur-state flow churn during playback.
- Automatic preview preparation no longer restarts its snapshot flow on every played frame.
- Background preview work stays paused while the timeline is playing, leaving the renderer focused on the preview.
- Reduced unnecessary recomposition and coroutine work in the preview path.

## Alight packages
- Broadened share-link host and URL resolution.
- Alight ZIP packages without a Schnitt manifest continue to import through scene XML and filename media matching.
- Public package URLs and signed download URLs are both accepted.
