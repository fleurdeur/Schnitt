# What's new in 5.3.2

**Glass and shake effects now use their real AM shader or motion controls, 7z plug-in packages import directly, and plug-in properties no longer fight the panel layout.**

## New features
- **Omino Glass native chain** - the nested Gaussian pass is now created as a real blur target, followed by the surface and final glass passes, instead of falling back to a generic distortion shader.
- **Glass and Glass2** - both distance-field passes run through the native multi-target engine.
- **Shake, Jitter, Oscillate and Swing** - shaderless auto-transform effects now generate motion controls from their own magnitude, frequency, evolution, seed, angle, slack and Z parameters.
- **Fade, Blink, Flicker and Pulse Opacity** - these now generate alpha shaders instead of a purple placeholder.
- **Spin and Pulsate** - generated rotation and scale shaders use their real RPM, frequency and size controls.
- **7z plug-in import** - 7z, ZXP and ZIP packages are unpacked, searched for scripts, panels, native plug-ins, shaders and effect metadata, and installed as one plug-in.
- **Archive password support** - the supplied plug-in archives are opened with the Keyflame password automatically.

## Fixed
- **Plug-in properties layout** - properties are now in one scrollable section instead of sharing a weighted nested list with the plug-in panel.
- **Plug-in custom UI** - the panel, generated effect controls and apply action no longer push the property rows off-screen.
- **Legacy engine** - the previous engine remains packaged and is still loaded automatically when the rebuilt engine cannot load.

## Improved
- **Omino Glass smoothing** - its feature-size parameter drives a real blur target used by the surface pass.
- **Effect clarity** - generated motion and alpha effects are labelled as native motion or opacity controls instead of a generic converted effect.
