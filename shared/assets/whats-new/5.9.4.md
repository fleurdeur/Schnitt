# Schnitt 5.9.4

This release fixes the install and startup problems in 5.9.3.

## What went wrong

- 5.9.3 enabled aggressive code and resource shrinking for the first time. That could remove classes and resources that are reached only from native callbacks, the package installer or reflection, which made the APK fail to install or crash at launch.
- 5.9.4 removes that experimental shrinking. It uses the same proven packaging path as 5.9.2.

## What is still smaller

- The standard APK still does not bundle the optional Aurea backend.
- Native engine libraries are still stripped.
- The redundant 64-bit fallback engine is still gone; 32-bit builds keep their fallback.
- The result is still much smaller than 5.9.2 without changing app behaviour.

## Kept from 5.9.3

- Fade In and Fade Out change layer opacity directly and work with all layer types.
- Motion Blur no longer turns layers white.
- More Alight effects use the native motion renderer; unsafe fallback matches are rejected.
- Project open is faster: one file read, background version snapshot, direct effect lookup and cached media checks.

## Aurea is now a plugin

- Aurea preset support is no longer a second APK. It is a downloadable plugin ZIP on the release page.
- Import it from Settings then Plugins then Import plugin. The app keeps its own After Effects project reader for aep files.
- The plugin is optional, ARM64 only and loads only after it is installed, so it no longer affects the app download.
