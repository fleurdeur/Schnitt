# What's new in 5.1.6

**Readable sections, correct plugin names, fixed preset effects, a working light theme, and safer imports.**

## Fixes
- Plugin file names now come from the document display name instead of the storage UUID, so ZXP/JSXBIN imports show real names.
- Plugin descriptions now use the manifest and panel metadata where available.
- Preset effect lookup now uses the full effect ID, so presets include real effects instead of only a gradient.
- Media tiles are wider and use two-line labels; Image library has its own tile.
- Plugin effects attach to the selected layer or the layer chosen in the dropdown.
- Removed unsafe arbitrary evalScript execution that could hang or time out; common effect calls are mapped to real layer effects.
- System-light resolves to the green Daylight theme instead of AMOLED.
- Audio library section labels are centered and no longer offset.
- Preset and TikTok category rows can be swiped horizontally.
- TikTok reads more results, caches/throttles requests, prefers direct video playback, and checks both description and page for XML.
- Pinterest/Cosmos image searches are cached, throttled and backoff-protected.

## Compatibility note
Adobe .aex files and Alight Motion .ta effect packages are encrypted/native binaries. The app can read their metadata and map supported effect contracts, but it cannot execute their proprietary shader machine code on Android. No unrelated effect is presented as the original binary effect.
