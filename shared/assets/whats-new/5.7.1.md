# Schnitt 5.7.1

This is a stability, compatibility and performance release.

## Directional Blur

- Rebuilt on a 65-sample directional gather adapted from Keyflow's directional blur.
- The smear is measured from the visible layer size, so it behaves the same on small and large layers.
- Alight directional blur keeps its strength and angle when imported from XML or a link.
- Old saved directional blurs stay compatible.

## Effect imports and duplicates

- Bundled Alight copies of effects that already have a native implementation are no longer listed twice.
- This removes the broken duplicate Directional Blur, Motion Blur, Rays, Cube, Grid, Page Curl, Raster Transform and Raster Extrude tiles.
- Imported Alight Motion Blur now resolves to Schnitt's own keyframe-aware Motion Blur.
- Curated Rays, Cube, Grid and Page Curl rules keep their settings and keyframes instead of falling back to a flat placeholder.
- Raster effects that cannot carry their full settings through a link are no longer offered as duplicate tiles.

## Depth maps

- Depth maps now match the model's native 518 px working size instead of producing a larger matte than the model can fill.
- Long clips use a lower depth sampling rate while keeping the original timestamps, duration and alignment.
- Depth inference runs with backend-aware parallelism, so NNAPI and XNNPACK devices no longer fight over too many jobs.

## Adaptive rendering

- While playing, preview quality now reacts to real render times, not only to the selected quality.
- Slow frames drop resolution in steps; fast frames recover it automatically.
- Paused previews return to the chosen quality.

## Large projects

- Layer and media lookups reuse the most recent immutable scene instead of rebuilding the list for every access.
- Timeline row lookup uses an id map, so selection and follow stay fast with many layers.
- Imported custom effect files are cached until they change.
- Heavy scenes automatically lower the background preview and pre-render resolution in steps, while light scenes keep full detail.
- Background preview and frame caching keep their existing memory-safe behaviour.

## Fixes

- Media URI decoding handles encoded dot segments and Windows file paths safely.
- Interrupted update downloads no longer leave an open part file on Windows.
- The full unit suite passes.
