# Schnitt 5.7.0 nightly

This is a nightly build. Features in it are experimental and may change before
the next stable release.

## AI agent over MCP

- Settings now has an AI agent (MCP) switch.
- While a project is open, Schnitt starts a local MCP server on your network.
- The settings card shows the endpoint and a private bearer token.
- Tools cover scene info, project XML, layer listing, selection, adding and
  deleting layers, property edits, keyframes, playhead control, undo and redo.
- The server is off by default and every request must carry the token.

## Animate model parts

- glTF and GLB models now keep their node parts after import.
- The model panel lists parts by node name.
- Each part has its own X, Y, Z, 3D rotation and scale controls with keyframes.
- Parts follow their glTF parent nodes, so moving a parent limb carries its child
  parts with it.
- Part transforms stay inside the existing model layer, so export and project
  XML keep working without a second animation system.

## Native engine and optimization

- Model part transforms are applied in the native Skia renderer, not in the
  Compose layer, so large meshes keep their draw cost.
- Release builds now use R8 full mode and resource shrinking.
- The existing camera track, stabilization, audio beat analysis and native DSP
  chain remain the engine used by nightly AI tools.

## Notes

- MCP is a local network feature. Use it only on a network you trust.
- Part animation is rigid per-node animation. Full skin deformation with a
  runtime bone hierarchy is not part of this nightly.
- Aurea's original native library is not linked. Its camera, motion, audio and
  glow ideas are available through Schnitt's own engine and the new MCP tools.
