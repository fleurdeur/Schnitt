# Schnitt 5.15.1

This release fixes media import from the AI agent and custom MCP connectors.

## Direct media links

- media.add now downloads a direct https media file and copies it into the project.
- A sharing page or HTML link is rejected with a clear message instead of being saved as a broken file.
- MP4, MOV, WebM, WAV, MP3, M4A, FLAC, PNG, JPEG and WebP links are recognized from the file itself when the server does not send a useful type.
- Use kind=audio to import only the audio track of a video. A WAV link imports directly as audio.
- Downloaded files keep their original name and stay available after the temporary download is removed.

## Picked files

- A content:// picker URI is copied into app storage before it is opened, so providers that cannot seek still work.
- A missing permission now explains that the file must be picked again.
- Video URLs are declared as video explicitly instead of falling back to an image check.

## Export and projects

- Existing projects, effects, keyframes and export quality are unchanged.
