# What's new in 5.1.5

**Readable media tiles**, working preset effects, fixed plugin application, a working light theme, and a more reliable TikTok browser.

## Fixes
- **Media tiles** — Image library has its own tile; Files and Clipboard are no longer compressed. Labels now use two lines and wider cells.
- **Presets** — Presets now look up effects with the correct full effect ID, wait for the effect catalog, and attach the real effect stack to the created layer. Presets are no longer gradient-only.
- **Plugins** — Plugin effects now resolve both short and full effect IDs, fall back to a real mapped effect, and attach to the selected layer or the layer chosen in the dropdown.
- **Plugin bridge** — Unsafe arbitrary evalScript execution was removed, preventing hangs and timeouts. Common `addProperty`/`addEffect` calls are intercepted and mapped to real layer effects.
- **Light theme** — System-light now resolves to the green Daylight palette instead of the AMOLED palette. The light palette uses a comfortable warm-neutral surface with green accents.
- **TikTok** — Two result pages are read, up to 24 results are kept, requests are cached/throttled with backoff, direct video URLs are preferred for preview, and XML import checks both the oEmbed description and the public page.
- **Image library** — Pinterest and Cosmos results are cached, throttled and backoff-protected; long-press adds the original image bytes without re-encoding.

## Optimizations
- Cached search results and HTTP caches for TikTok, Pinterest and Cosmos.
- Cached plugin catalogs and properties.
- Lighter preset thumbnail compositing using the vector placeholder.
- Existing pre-render and ONNX session optimizations retained.

## Notes
- Alight Motion `.ta` effect assets in third-party binaries are encrypted and cannot be executed or copied as shaders. Schnitt continues to use its own shader catalog and the existing Alight XML effect migration table for imported projects.
