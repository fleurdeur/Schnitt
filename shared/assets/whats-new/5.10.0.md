# Schnitt 5.10.0

Real support for community effect packs, native scene effects, and a faster editor.

## Effect packs that work

- Imported Alight effect packs now keep every pass. Horizontal and vertical blur chains, bloom, halation, edge glow, VHS suites and other multi-stage effects render as separate stages instead of one wrong shader.
- Open and self-closing pass tags both work. Effects are no longer lost when a pack writes a pass as an open and close pair.
- Effects that store their id as hexadecimal are decoded correctly.
- Shaders with whitespace after their CDATA block are found.
- A pack with a vertex shader before its fragment shader now uses the fragment stage.
- Feed-back passes that name their own effect no longer discard the whole effect.
- Texture paths from resource, textures and assets folders all resolve.

## ZIP packs

- Import a whole community ZIP from the effects browser. Every XML and every texture is unpacked and the effects appear in the library.
- A single XML still imports as before.
- Pack entries are bounded and paths outside the pack are rejected.

## Native scene effects

- Grow Parts scales parts by their depth and progress.
- Shake Parts moves parts with smooth noise and keeps deeper parts steadier.
- Morph Path blends the layer outline into the outline of the layer below it.
- Manual Shake, Manual Shake 2, Pose Shake, Transform, V Transform, Face Motion and Perlin Displace are now implemented natively with their real controls.
- Move Along Path versions 1 and 2 now use the same native path engine as version 3.

## Faster

- The effect catalog no longer rebuilds its tile list for every browser redraw.
- Imported custom effects keep their decoded textures instead of reloading them on every catalog refresh.
- Morph Path caches its sampled outline for repeated draws in one frame, including motion blur and echo passes.
- Existing fast paths for saved Schnitt projects, link-free projects and seekable package imports are kept.

## Still included

- Motion Blur draws the real image or video.
- Import warnings list effects that could not be carried over.
- Settings > Advanced: debug log records imports, conversions, project opens and failures.
