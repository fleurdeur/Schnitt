# What's new in 5.3.0

**Depth maps are dramatically faster, After Effects projects open as editable scenes, and Alight Motion multipass effects now compile their real pass chains instead of being replaced by a generic filter.**

## New features
- **After Effects projects** - Schnitt now opens .aep and .aepx files, reads compositions, size, frame rate, duration, background colour and layer records, and creates an editable scene for each composition.
- **After Effects binary reading** - .aep files are parsed directly as RIFX/Egg! data, including Fold, Item, cdta, Layr and ldta chunks, without running After Effects or any plug-in.
- **After Effects XML reading** - .aepx compositions and layer metadata are read from the project XML.
- **Real multipass effect chains** - Alight Motion effects with passes and buffer textures now compile their actual horizontal, vertical, distance-field and similar stages in order, including reads from the intermediate buffer.
- **Nested pass safety** - multipass effects that depend on another effect inside a pass still use the compatibility conversion instead of rendering an incorrect chain.

## Fixed
- **Depth map speed** - depth inference now uses NNAPI with fp16 when the device can run it, falls back to XNNPACK and then CPU, and verifies the accelerator before using it.
- **Parallel depth frames** - depth frames are inferred in parallel batches instead of one serial frame at a time.
- **Depth memory and resizing** - output extraction no longer boxes every value in an ArrayList, and depth is scaled back with bilinear sampling instead of nearest-neighbour blocks.
- **Old Flash files** - binary FLA files are detected correctly again after the project header change.
- **After Effects layer visibility** - layer video flags from ldta are respected, so disabled AE layers start hidden.
- **After Effects media types** - Android now offers Schnitt for .aep, .aepx and the common After Effects MIME types.

## Improved
- **Depth quality** - resizing keeps smooth edges in the generated depth video while using the same real Depth Anything V2 model.
- **Effects library** - Alight Motion effects keep their parameters and now show whether their pass chain was compiled or converted for compatibility.
- **Project import reporting** - imported After Effects compositions use the same title, missing-media and language reporting as other project formats.
